# Лендинг для практического курса по нейросетям «ESSENS.AI»

<img width="1065" height="546" alt="Снимок экрана 2026-10-26 в 4 25 23 PM" src="https://github.com/user-attachments/assets/07a4ec06-2303-475e-9665-0daf4c7124ab" />

**О проекте:**
Промо-страница для образовательного курса по искусственному интеллекту. Задача — понятно объяснить пользу продукта, показать программу и мотивировать оставить заявку.

**Что сделано:**
- Сверстал объемную страницу с четкой структурой и понятными блоками (программа, спикеры, тарифы).
- Обеспечил высокую читаемость текста и аккуратную типографику.
- Настроил адаптивность: на мобильных устройствах все элементы аккуратно перестраиваются в колонку.
- Добавил интерактивные элементы (аккордеоны, кнопки призыва к действию).

**Стек:**
- HTML5
- CSS3
- JavaScript
